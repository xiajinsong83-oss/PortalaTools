**单词记忆卡**：在线单词记忆卡（抽认卡 / flashcard）：把词表按「正面 Tab 背面」每行一条粘贴进来，或导入 txt/csv 文件、逐张手动添加，就能建成自己的卡组；学习时点卡翻面并按「认识 / 忘了」评分，工具用莱特纳五盒法安排复习顺序，记住的卡越隔越久出现、忘掉的很快排回来。支持乱序与可复现种子、正反面互换、选择题与拼写三种练法，能按面选中英文朗读，一轮结束给正确率与错题清单并可一键只练错题；还能打印 A4 词表版、默写版和可裁剪的卡片版（双面打印自动镜像列序）。卡组与进度只存在本机浏览器，可导出 JSON 备份或一键清空，纯前端运行、不上传。
