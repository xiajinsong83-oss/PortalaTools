**IP 地址查询**：免费在线 IP 地址查询：点一下就能查到你当前的公网 IP 与归属地（这一步会向第三方 IP 库发一次请求，页面会先告诉你发给谁，并顺带探测你有没有 IPv6 出口）；把任意 IPv4、IPv6 或 CIDR 网段贴进输入框，还能离线算出网络地址、广播地址、子网掩码、通配符掩码、可用主机数与 IP 范围，做子网划分与 IP 范围转最小 CIDR 集合。认得 2130706433、0x7f000001、127.1、010.0.0.1 这些会引发歧义的历史写法并解释清楚，也能判断 192.168、100.64、169.254、fe80 各是什么。批量模式可从访问日志里抽 IP 并按 /24 聚合统计。你输入的 IP 只在浏览器本地解析，不会发送到任何服务器。
